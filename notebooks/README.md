# Notebook plan

The app is the interactive deliverable; use these notebooks for a documented research narrative.

Recommended notebook sequence:
1. `01_data_audit.ipynb` — file inventory, schema, season coverage, nulls, duplicate deliveries, data-quality checks.
2. `02_tournament_trends.ipynb` — season scoring, innings, toss, venue and outcomes.
3. `03_batting_analysis.ipynb` — batting metrics, phase splits, consistency, boundary and dot-ball profiles.
4. `04_bowling_analysis.ipynb` — economy, wickets, legal-ball calculations, phase splits and dismissal types.
5. `05_batter_bowler_matchups.ipynb` — head-to-head tables with minimum sample thresholds.
6. `06_team_strategy.ipynb` — batting-first vs chasing, phase profiles, powerplay/death patterns.
7. `07_advanced_analytics.ipynb` — clustering and carefully validated prediction baselines.

Avoid publishing a conclusion before checking its denominator, sample size and data limitations.
